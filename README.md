# Jinge Ma Homepage

This repository hosts my personal academic website.

- Website: https://jingema99.github.io/jingema.github.io/
- Google Scholar: https://scholar.google.com/citations?user=xl5EUwcAAAAJ&hl=en

I am a Ph.D. candidate in Electrical and Computer Engineering at Purdue University (VIPER Lab).

## Structure

- `index.html` — the whole site (About, News, Publications, Talks, Education)
- `assets/css/style.css` — styles (light and dark mode)
- `assets/img/profile.jpg` — profile photo
- `assets/img/pubs/` — publication thumbnails
- `assets/pdf/CV_Jinge.pdf` — CV
- `assets/pdf/prelim_slides.pdf` — preliminary exam slides

To add a paper, copy one `<article class="pub">` block in `index.html` and drop a thumbnail into `assets/img/pubs/`.
